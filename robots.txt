# This is a private portfolio demo. It must not appear in search results.
#
# Crawling is deliberately ALLOWED so that crawlers can fetch each page and
# read its <meta name="robots" content="noindex"> tag, which is what actually
# removes a URL from an index. A blanket "Disallow: /" would hide that tag,
# and search engines can still list a URL they were blocked from crawling if
# they find it linked elsewhere. Allow + noindex is the combination that works.

User-agent: *
Allow: /
